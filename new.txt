Absolutely! Here’s a **step-by-step guide** to cleanly delete your old deployment and redeploy your Node.js backend (and optionally frontend) on your server, with CORS open to all.

---

## **1. Stop the Running Backend**

If you used `pm2`:
```bash
pm2 stop er_server
pm2 delete er_server
```
Or, if you started with `node index.js`, just `Ctrl+C` in that terminal or kill the process.

---

## **2. Delete Old Files**

Assuming your project is in `/opt/ER_Linux`:
```bash
sudo rm -rf /opt/ER_Linux
```
*(Double-check the path before running this!)*

---

## **3. Re-Clone the Repository**

```bash
cd /opt
sudo git clone https://github.com/vandralcapital/erapp.git ER_Linux
sudo chown -R $USER:$USER /opt/ER_Linux
```

---

## **4. Install Backend Dependencies**

```bash
cd /opt/ER_Linux/server
npm install
```

---

## **5. (Optional) Install Frontend Dependencies and Build**

If you want to deploy the frontend as well:
```bash
cd /opt/ER_Linux/frontend
npm install
npm run build
```

---

## **6. Enable CORS for All Origins in Backend**

Edit `/opt/ER_Linux/server/index.js` (or your main server file):

```js
const cors = require('cors');
app.use(cors()); // Add this line near the top, before your routes
```

---

## **7. Start the Backend on All Interfaces**

Edit your listen line to:
```js
app.listen(3000, '0.0.0.0', () => {
  console.log('Server running on port 3000');
});
```
Then start your backend:
```bash
cd /opt/ER_Linux/server
node index.js
# Or, for production:
pm2 start index.js --name er_server
```

---

## **8. (Optional) Open Firewall Port**

If you have a firewall, open port 3000:
```bash
sudo ufw allow 3000
```

---

## **9. Test Your Backend**

Visit:
```
http://<your-server-ip>:3000/create_admin
```
or any other backend route.

---

## **10. (Optional) Nginx for SSL**

If you want to use Nginx for SSL, set up a simple reverse proxy to `localhost:3000`.  
But for direct IP access, you don’t need Nginx.

---
