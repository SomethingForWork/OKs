Perfect plan! Here’s a **step-by-step, foolproof guide** to completely clean up and redeploy your app from scratch, ensuring no old permissions or config issues remain.

---

## **1. Stop All Running Services**

If you’re using pm2:
```bash
pm2 stop er_server
pm2 delete er_server
```
Or kill any running Node.js processes related to your app.

---

## **2. Delete the Old Deployment**

**WARNING:** This will remove all your app files in `/opt/ER_Linux`!
```bash
sudo rm -rf /opt/ER_Linux
```

---

## **3. Re-Clone the Repository**

```bash
cd /opt
sudo git clone https://github.com/vandralcapital/erapp.git ER_Linux
sudo chown -R $USER:$USER /opt/ER_Linux
```

---

## **4. Install Backend Dependencies**

```bash
cd /opt/ER_Linux/server
npm install
```

---

## **5. Install Frontend Dependencies and Build**

```bash
cd /opt/ER_Linux/frontend
npm install
npm run build
```

---

## **6. Set Permissions (Critical Step!)**

```bash
sudo chmod -R o+r /opt/ER_Linux/frontend/build
sudo find /opt/ER_Linux/frontend/build -type d -exec chmod o+x {} \;
sudo chmod o+x /opt /opt/ER_Linux /opt/ER_Linux/frontend
```

---

## **7. Restore Your Old Working Nginx Config**

- Replace your current Nginx config with the old, working one.
- Make sure the `alias` and `root` paths match your new deployment.
- Test and reload Nginx:
  ```bash
  sudo nginx -t
  sudo systemctl reload nginx
  ```

---

## **8. Start the Backend**

```bash
cd /opt/ER_Linux/server
pm2 start index.js --name er_server
# or
node index.js
```

---

## **9. Test Everything**

- Visit your site in the browser.
- Check static files, API, and login.
- If you see any errors, check Nginx and Node logs.

---

## **10. (Optional) Automate Permissions After Every Build**

Add this to your deployment script or CI/CD:
```bash
sudo chmod -R o+r /opt/ER_Linux/frontend/build
sudo find /opt/ER_Linux/frontend/build -type d -exec chmod o+x {} \;
sudo chmod o+x /opt /opt/ER_Linux /opt/ER_Linux/frontend
```

---

**You will now have a clean, working deployment with no leftover issues!**
