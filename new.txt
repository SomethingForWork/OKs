Absolutely! Here’s a **step-by-step guide** to get your React frontend and Node.js backend running together perfectly, using Nginx as a reverse proxy for production. This will ensure:

- The frontend is served at `https://uat-ers.religare.in` (or your IP).
- The backend API is accessible at the same domain (no CORS issues).
- All routes (e.g., `/create_admin`) are handled correctly.

---

## **1. Build and Prepare the Frontend**

```bash
cd /opt/ER_Linux/frontend
npm install
npm run build
```
This creates `/opt/ER_Linux/frontend/build` with your static files.

---

## **2. Prepare the Backend**

- Make sure your backend is running on port 3000 and listening on `0.0.0.0`.
- In `/opt/ER_Linux/server/index.js`, set CORS to allow only your domain (for security):

  ```js
  const cors = require('cors');
  app.use(cors({
    origin: 'https://uat-ers.religare.in',
    credentials: true
  }));
  ```

- **(Optional for local testing):** Use `app.use(cors());` to allow all origins.

- Start your backend:
  ```bash
  cd /opt/ER_Linux/server
  pm2 start index.js --name er_server
  # or
  node index.js
  ```

---

## **3. Nginx Configuration**

Edit your Nginx config (e.g., `/etc/nginx/sites-available/er_linux`):

```nginx
server {
    listen 443 ssl;
    server_name 10.91.41.16;

    ssl_certificate /etc/ssl/religare/religare.in.crt;
    ssl_certificate_key /etc/ssl/religare/religare.in.key;

    root /opt/ER_Linux/frontend/build;
    index index.html;

    location /static/ {
        alias /opt/ER_Linux/frontend/build/static/;
        expires 30d;
        add_header Cache-Control "public, max-age=2592000";
    }

    location ~* \.(?:ico|css|js|gif|jpe?g|png|woff2?|ttf|svg|eot|otf|json)$ {
        try_files $uri =404;
        expires 30d;
        add_header Cache-Control "public, max-age=2592000";
    }

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 80;
    server_name 10.91.41.16;
    return 301 https://$host$request_uri;
}
```

**What this does:**
- Serves static frontend files directly.
- Proxies all other requests (like `/create_admin`, `/login`, etc.) to your backend.
- No `/api` prefix needed.

---

## **4. Permissions**

Make sure Nginx can read the frontend build:
```bash
sudo chown -R www-data:www-data /opt/ER_Linux/frontend/build
sudo chmod -R 755 /opt/ER_Linux/frontend/build
sudo find /opt/ER_Linux/frontend/build -type f -exec chmod 644 {} \;
sudo find /opt/ER_Linux/frontend/build -type d -exec chmod 755 {} \;
```

---

## **5. Reload Nginx**

```bash
sudo nginx -t
sudo systemctl reload nginx
```

---

## **6. Test Everything**

- Visit `https://uat-ers.religare.in` in your browser.
- The React app should load.
- Backend routes (like `/create_admin`) should work from the same domain.
- No CORS errors should occur.
