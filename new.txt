## ❌ Why You're Still Not Seeing "Secure" (Padlock)

Even though the cert is correct, browsers might **still show "Not Secure"** because of **missing intermediate certificate (chain)**.

## 🔧 FIX — Add Intermediate Certificate to Nginx

### Step 1: **Download the Chain Cert**

Download the intermediate certificate (GlobalSign chain):

```bash
wget -O /etc/ssl/religare/globalsign-chain.crt http://secure.globalsign.com/cacert/gsrsaovsslca2018.crt
```

### Step 2: **Bundle the Cert + Chain**

Create a full chain file:

```bash
cat /etc/ssl/religare/religare.in.cer /etc/ssl/religare/globalsign-chain.crt > /etc/ssl/religare/fullchain.pem
```

### Step 3: **Update Nginx Config**

Edit your Nginx block to use the fullchain:

```nginx
ssl_certificate /etc/ssl/religare/fullchain.pem;
ssl_certificate_key /etc/ssl/religare/religare.in.key;
```

✅ You **don’t need to set `ssl_trusted_certificate`** unless you're doing client cert auth.

---

### Step 4: **Restart Nginx**

```bash
sudo nginx -t   # Check for syntax issues
sudo systemctl reload nginx
```
